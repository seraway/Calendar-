# Work Tasks Calendar — Οδηγίες εγκατάστασης

## Τι περιλαμβάνει
- Calendar ημέρας/εβδομάδας/μήνα και λίστα επόμενων εργασιών
- Task name και προαιρετικό description
- Low / Medium / High priority
- Επανάληψη: μία φορά, κάθε μέρα, Δευτέρα–Παρασκευή, επιλεγμένες ημέρες εβδομάδας, κάθε μήνα
- Ολοκλήρωση εργασιών ανά ημερομηνία
- Αποθήκευση τοπικά στη συσκευή και βασική λειτουργία offline μετά την πρώτη φόρτωση

## Σημαντικό
Αυτό είναι το πλήρες πακέτο πηγαίων αρχείων μιας PWA, όχι APK. Για να εμφανιστεί η επιλογή εγκατάστασης στο Android, η εφαρμογή πρέπει να ανέβει σε HTTPS hosting. Το άνοιγμα του `index.html` απευθείας από ZIP/Downloads δεν αρκεί για να εγκατασταθεί ως PWA. Τα δεδομένα αποθηκεύονται τοπικά στο συγκεκριμένο browser/tablet· δεν υπάρχει ακόμη συγχρονισμός μεταξύ συσκευών.

## Ο πιο απλός τρόπος δημοσίευσης (GitHub Pages)
1. Σε υπολογιστή άνοιξε ή δημιούργησε λογαριασμό στο GitHub.
2. Δημιούργησε νέο repository, π.χ. `work-tasks-calendar`.
3. Ανέβασε όλα τα αρχεία αυτού του φακέλου στο repository (όχι τον φάκελο ZIP ως ένα αρχείο).
4. Στο repository πήγαινε **Settings → Pages**.
5. Στο **Build and deployment**, επίλεξε **Deploy from a branch**, branch **main**, folder **/(root)** και πάτησε **Save**.
6. Περίμενε να εμφανιστεί η διεύθυνση Pages, συνήθως `https://USERNAME.github.io/work-tasks-calendar/`.
7. Άνοιξε αυτή τη διεύθυνση στο Chrome του Android tablet.
8. Πάτησε το μενού ⋮ του Chrome και διάλεξε **Install app** ή **Add to Home screen** (η ονομασία μπορεί να διαφέρει). Επιβεβαίωσε την εγκατάσταση.
9. Άνοιγε πλέον το Work Tasks από το εικονίδιο στην αρχική οθόνη.

## Δοκιμή
- Πάτησε **New task**
- Γράψε τίτλο, προαιρετική περιγραφή και priority
- Διάλεξε repeat και ημέρες όπου χρειάζεται
- Πάτησε Save task
- Διάλεξε την ημερομηνία στο calendar και δοκίμασε το checkbox ολοκλήρωσης

## Αποθήκευση και ιδιωτικότητα
Οι εργασίες αποθηκεύονται στο `localStorage` του browser. Μην καθαρίσεις τα δεδομένα του browser αν θέλεις να κρατήσεις τις εργασίες. Προς το παρόν, η εφαρμογή δεν συγχρονίζει δεδομένα με άλλο tablet/κινητό. Η εξωτερική γραμματοσειρά μπορεί να μην εμφανίζεται offline, αλλά η εφαρμογή λειτουργεί με εναλλακτικές γραμματοσειρές.
